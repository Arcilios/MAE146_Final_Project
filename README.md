## File Description

- `data/`: Contains the California Housing dataset used in this project.
- `docs/`: Contains the final project report in PDF format.
- `figures/`: Contains generated plots used in the report.
- `scripts/`: Contains Python scripts for data loading, Ridge Regression, and neural network training.
- `analysis.ipynb`: Main notebook for exploratory analysis, model training, and visualization.
